# ILVAD 的改进方向（基于实测的十条）

> 这份文档记录 2026-11 在 RTX 3090 上用**官方未改动代码**跑出来的证据，以及由此推出的改进点。
> 所有数字都来自 `official/out_*` 下的原始输出，可在服务器复现。

## 0. 先说结论

ILVAD 在 POPE random 1000 题上的实测（官方代码、未改动、`DISABLE_TORCH_COMPILE=1` 已验证不改输出）：

| α | acc | yes-rate | precision | recall | vs greedy | p |
|---|---|---|---|---|---|---|
| greedy | 88.50% | 49.5% | 0.889 | 0.880 | — | — |
| 2.5 | 88.50% | 50.9% | 0.878 | 0.894 | +0.00 | 1.000 |
| **5.0** | **90.70%** | 46.9% | **0.934** | 0.876 | **+2.20** | **0.0013** |
| 7.5 | 73.10% | 71.7% | 0.661 | 0.948 | −15.40 | <0.0001 |
| 10 | 58.10% | 88.9% | 0.546 | 0.970 | −30.40 | <0.0001 |

**方法是对的，但 α 是一道悬崖**：2.5 无效、5.0 最优、7.5 崩盘。翻倍就报废。

---

## 1. 三个病灶

### 病灶 1：干预强度没有约束

α 只控制「乘多少倍」（e^α），没有任何机制保证乘完之后注意力分布仍然合理。
α=7.5 时视觉质量坍缩到少数 token 上，模型失去「验证某物不在场」的能力，退化成「什么都说有」（yes-rate 88.9%）。

### 病灶 2：证据图是二值的、冻结的、大部分与问题无关

- **二值**：`Ā > τ·mean` 之后 0/1，信息全丢。实测 τ=2/5/8 时非零 token 数从 171 掉到 41。
- **冻结**：T=10 步后不再更新。
- **无关**：null-prompt 探针显示 top-10 token 重叠 **84—92%** —— 模型盯着的 token 九成与问题无关，它们是 sink 不是证据。

### 病灶 3：干预发生在每一步，而不是决策点

幻觉产生于**输出实体名词**那一刻。现在的做法每步都推，把不该动的步骤也动了。

---

## 2. 五个改进点

| # | 改法 | 病灶 | 预期 | 成本 |
|---|---|---|---|---|
| A | 预算化干预（约束 KL 或熵） | 1 | 消除悬崖 | 极低 |
| B | 支持集下界（有效 token 数下限） | 1 | 防坍缩、抬高峰值 | 极低 |
| C | Query 条件化（减 null-prompt 图） | 2 | 去 sink、图变准 | 一次额外 prefill |
| D | 决策点触发（只在实体词处干预） | 3 | 减少副作用 | 低 |
| E | 连续层权重（softplus 替代二值跳变） | 2 | 保留层强弱 | 极低 |

### A. 预算化干预

现在：`a_ij ← a_ij · exp(α · Ŝ_j)`，再归一化。α 的物理意义依赖模型与序列长度。

改成：**给定注意力偏移预算 ε，反解 α**

```
α* = argmin_α | KL( a(α) ‖ a(0) ) − ε |
```

或更简单，按行熵：取 α 使 `H(a(α)) = (1−ρ)·H(a(0))`。

ρ 表示「把注意力收紧多少」，**与模型、精度、层数无关**。α=5 在 LLaVA-7B 上约等于 ρ≈0.3，换到 13B 是另一个 α 但同一个 ρ。

### B. 支持集下界

坍缩的本质是支持集太小。加硬约束：

```
有效支持集（perplexity = exp(H)）不得少于 K 个 token
```

实现上就是给 α 加上界，per-row 算 perplexity，超过下限就压 α。

### C. Query 条件化

```
Ŝ_final = Ŝ(q, image) − Ŝ(q_null, image)
```

理论：sink 的定义就是「对问题不敏感的注意力」，相减留下的正是 query 敏感部分。
同学测到的 84—92% 重叠率是这条的强证据。他们做成了减常数 λ，那只是均值平移，不如真的做对比。

### D. 决策点触发

只在 top-1 候选是名词时施加干预。预期：α 窗口变宽、文本退化减少（实测 α 大时复读率 10.6%→40.8%）。

### E. 连续层权重

```
S_j = Σ_l softplus( Ā_{l+1,j} − Ā_{l,j} )
```

保留「涨了多少」，而不只是「涨没涨」。

## 3. 要「比它更好」，三条不同量级的路

### 路线 1：同量级改良（训练-free）

A+B+C+D 组合。目标不是提几个点，而是**消除悬崖**——让方法在 α 变化 5 倍内都稳定。
价值：补上论文缺的那块拼图（安全区 + 约束条件）。

### 路线 2：换赛道——把图蒸成探针

现在的干预需要物化整个注意力矩阵（32 层 × 576 token）。我们测过探针能学到 60% 相关、0.28 top-30 IoU。
**IoU 到 0.6 就能完全替代注意力计算，推理零额外开销。**
需要换目标函数（top-k 排序损失替代 BCE）+ 更多训练数据。

### 路线 3：换范式——生成后验证

生成 caption → 抽名词 → 遮蔽检验 → 不一致就重写。绕开注意力，但成本 ×(名词数)。

## 4. 评测层面（论文真正的软肋）

**① CHAIR 被长度污染**：20 个配置，Pearson r = 0.807，`CHAIR_S ≈ 0.63 × 词数 − 16.8`。
同学的「大幅改进」在长度匹配后基本归零。

**② ILVAD 让文本质量退化**：重复 5-gram 10.6%→40.8%，不足 20 词 0%→5.2%，最长 caption 156→389 词。CHAIR 对此免疫。

**建议**：长度匹配的 CHAIR、复读率作为常规指标、AOPC + 随机基线（实测 14.7× 随机）。

## 5. 优先级

**课程项目**：A+B（20 行代码，2 小时出结果）→ 评测三条（用已有数据）→ 「我的实现 vs 官方实现」排查链作为附录。

**投稿**：C+D（真正的新意）→ 路线 2 的 IoU 提升 → 评测三条作为标配。

---

## 6. 一句话

> 这篇论文的方法是对的，但它把一个**应该被约束的量（注意力要收紧多少）当成了自由参数（α）**，于是最优点变成了一道悬崖。
> 改进的核心不是「再调一个更好的 α」，而是**把 α 换成一个有物理意义、可跨模型迁移的约束**。
